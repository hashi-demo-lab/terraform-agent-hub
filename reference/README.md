# reference/

Hub-only authoring guides for content authors. These files are **not synced** to downstream repos.

## Contents

| File | Description |
|------|-------------|
| [skills-authoring-guide.md](skills-authoring-guide.md) | Comprehensive guide for writing SKILL.md files |
| [agent-authoring-guide.md](agent-authoring-guide.md) | Guide for writing agent `.md` files |
| [AGENT-DEFINITION-TEMPLATE.md](AGENT-DEFINITION-TEMPLATE.md) | Copy-and-fill template for new agent definitions |

## Usage

Read these guides before creating new skills or agents in this hub. The pre-commit hooks in `hooks/` enforce many of the rules described here — commit-time validation will catch spec violations before they're synced downstream.
